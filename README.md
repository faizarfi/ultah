# Nadia Cindy Novita Sari — Chapter 26 (Exclusive Digital Birthday Letter)

Website kartu ucapan ulang tahun digital satu halaman (single-page) bertema **Futuristic Editorial Design** berformat lembar surat digital premium untuk **Nadia Cindy Novita Sari (Mbakyu)** dari **faiz wlekk**.

---

## Fitur Utama

- **A4 Digital Sheet Experience**: Dirancang proporsional seperti lembar surat cetak arsip A4 dengan tekstur kertas *off-white/ivory*, garis geometris tipis, sudut *crop marks*, dan aksen *electric green* halus.
- **Tipografi Eksklusif & Modern**: Menggunakan kombinasi font *Space Grotesk* dan *Inter* untuk tata letak editorial berkelas internasional.
- **Visual Centerpiece**: Angka **26** berukuran besar dengan estetika arsitektural futuristik.
- **Single Editorial Portrait**: Area foto tunggal yang menyatu dengan lembaran surat, dilengkapi *fallback placeholder* elegan dan panduan peletakan foto.
- **Fitur Simpan PDF / Cetak A4**: Dilengkapi tombol cetak teroptimasi (`@media print`) yang otomatis memformat halaman menjadi dokumen kenangan tanpa ornamen browser.
- **Interaksi Halus**: Efek *fade-in* staggered saat pertama kali dimuat, hover interaktif, serta tombol verifikasi stempel arsip resmi.
- **Bebas Polusi Visual**: Tanpa emoji, tanpa balon, tanpa confetti, dan tanpa musik otomatis.

---

## Cara Menjalankan Proyek

1. **Jalankan development server**:
   ```bash
   npm run dev
   ```
2. Buka browser di [http://localhost:3000](http://localhost:3000).

3. **Untuk build production**:
   ```bash
   npm run build
   npm run start
   ```

---

## Cara Mengganti Foto Nadia

1. Siapkan 1 file foto Nadia (format potret 3:4 atau 4:5 disarankan).
2. Simpan file foto tersebut ke:
   ```text
   public/nadia.jpg
   ```
3. Refresh halaman website. Foto akan otomatis muncul pada bingkai editorial.
4. *Opsional*: Kamu juga bisa mengklik tombol **"Pratinjau Foto"** di pojok kanan atas website untuk menguji coba tampilan foto secara langsung di browser tanpa perlu me-refresh.
